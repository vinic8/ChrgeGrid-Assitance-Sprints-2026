## Convenção de versionamento

- Cada mudança de conteúdo do system prompt gera um novo arquivo `system_prompt_vN.md`
  (nunca sobrescrever uma versão já avaliada).
- `src/config.py` aponta para a versão ativa via `SYSTEM_PROMPT_VERSION` (env var,
  default `v5`), permitindo rodar o eval contra qualquer versão histórica sem editar código.
- Toda nova versão precisa: (1) motivo da mudança, (2) diff conceitual resumido nesta
  tabela, (3) reexecução do eval set (`evals/eval_cases.py`) antes de virar padrão.
